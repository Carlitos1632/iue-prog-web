##  Descripción
Este proyecto corresponde a una actividad práctica de control de versiones utilizando Git y GitHub.  
Se simula el trabajo colaborativo entre dos estudiantes mediante el uso de ramas, merges y revert.

---

##  Flujo de trabajo realizado

1. Creación del repositorio y archivo HTML base.
2. Creación de rama `feat-header` para agregar el header.
3. Creación de rama `feat-footer` para agregar el footer.
4. Integración de ramas en `main` mediante **merge**.
5. Resolución de cambios en el archivo `index.html`.
6. Uso de **git revert** para deshacer cambios y evidenciar control de versiones.
